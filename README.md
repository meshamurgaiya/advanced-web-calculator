# Advanced Web Calculator

A professional web calculator built using HTML, CSS, and JavaScript.

## Features

- Basic Arithmetic Operations
- Square Root Function
- Square Function
- Percentage Calculation
- Backspace Support
- Calculation History
- Clear History
- Local Storage Support
- Dark/Light Theme Switch
- Responsive Design
- Keyboard Support
- Error Handling

## Technologies Used

- HTML
- CSS
- JavaScript
